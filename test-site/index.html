대기
📄 검색 본문 (검색/Ctrl+F 대상)
RBI(Remote Browser Isolation, 원격 브라우저 격리)는 위험한 웹사이트를 사용자 PC가 아닌 서버 측 격리 브라우저로 열어 악성코드와 정보 유출을 차단합니다. AirRBI는 IG 게이트웨이가 인증·정책을 적용하고, 격리 브라우저(UG)가 실제 사이트를 렌더링하며, LiteClient가 픽셀 스트리밍으로 화면을 받습니다. 클립보드·다운로드·인쇄·워터마크 같은 DLP 정책으로 데이터 반출을 통제하고, 파일은 CDR 무해화를 거칩니다. 이 문장에서 "RBI", "격리", "정책", "AirRBI" 등을 검색해 하이라이트 동작을 확인하세요.

④ 서식(text/html) · 특수문자 복사

서식/따옴표·개행·data-pm-slice 페이로드를 복사 → 대상칸에 Ctrl+V. (ug 3.3.x 클립보드 audit 파싱 회귀 검증)

RBI 서식 복사 테스트 — 따옴표"·개행↵·특수 <pm-slice>

B 📁 파일 다운로드 · 업로드 · 바이러스/무해화

① 기본 다운로드 (파일보관함 라우팅 · CDR)

다운로드 → RBI가 가로채 파일보관함으로 라우팅·CDR 검사(검사중→완료).

대기

② 검사 대상 파일 (바이러스 / 무해화 / FAILED)

파일보관함의 바이러스·무해화 검사 컬럼(scanTypes) 노출과 상태(검출/BLOCKED/FAILED)를 유발.

대기

③ 파일 업로드 (OPEN 다이얼로그 브리지)

격리에서 내 PC 파일 선택(OPEN 다이얼로그)이 클라이언트로 브리지되는지. 대용량 생성 버튼으로 업로드 취소/중복 시나리오도.

대용량 생성: → 받아서 파일보관함에 업로드
대기

④ 다운로드 방식 다변화 (다운로드 미발생 이슈 재현)

showSaveFilePicker는 UG가 SAVE 다이얼로그 자동취소 → AbortError로 다운로드 미발생 재현. 나머지 방식과 결과 비교.

대기

C 🗔 팝업 / 새 탭 새 창 격리 · 캐시비우기

새 탭/팝업으로 격리 세션이 뜨는지, 이후 사용자메뉴(캐시비우기 등) 동작(팝업탭 무한로딩 이슈 재현 경로).

대기
