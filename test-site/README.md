# RBI 사용자 포털 — 테스트 타겟 사이트

격리 브라우저(웹 격리 뷰어)와 사용자 포털의 **모든 DLP·렌더링·입력 기능을 한 페이지에서** 검증하기 위한 자기완결형 테스트 사이트입니다. 외부 의존성 없는 단일 `index.html`(일부 미디어/외부 iframe만 네트워크 필요).

## 1. 무엇을 테스트하나 (섹션 = 테스트 항목)

| 섹션 | 영역 | 핵심 확인 |
|---|---|---|
| A | 환경/렌더링 정보 | 원격(UG) userAgent·해상도·시간대 표시, 직접 열기와 비교 |
| B | 화면 렌더링 | 색상/이미지/애니메이션/캔버스/스크롤 — 픽셀 스트리밍 깨짐·끊김 |
| C | 입력/IME/마우스 | 키보드·한글(IME 조합 이벤트)·클릭/우클릭/이동·키 이벤트 |
| D | 클립보드(DLP) | 원격→로컬 복사, 로컬→원격 붙여넣기, 대용량(~10MB), 민감정보형 |
| E | 다운로드/CDR | .txt/.csv/.png/.docx/.zip/.exe — 차단/허용·CDR 무해화·대용량 |
| F | 업로드(DLP) | 단일/다중 파일 선택, 드래그앤드롭 |
| G | 인쇄 | window.print()·영역 인쇄, 인쇄물 워터마크 |
| H | 팝업/네비 | window.open·target=_blank·허용/미허용 사이트 이동(차단 기대)·폼 제출 |
| I | 미디어 | HTML5 동영상·오디오 비프·카메라(getUserMedia/WebRTC) |
| J | iframe | 내부(srcdoc)/외부 iframe 렌더·입력 |
| K | 스트리밍 | AI 챗봇류 점진적 출력 모사(부분 갱신 성능) |
| L | 워터마크 | 화면 전체 타일 표시·제거 불가·캡처/인쇄 포함 |
| M | 동적/성능 | 고부하 애니메이션·실시간 시계로 입력→화면 지연 관찰 |

우하단 **이벤트 로그**에 모든 동작(클릭/입력/복사/다운로드/팝업 등)이 타임스탬프와 함께 기록됩니다.

## 2. 사용 방법

### (1) 기준선(baseline) — 일반 브라우저로 직접
```
# 파일을 그대로 열거나, 간단히 호스팅
cd C:\Development\Project\RBI\rbi.ai\test-site
python -m http.server 8900      # → http://localhost:8900
```
각 버튼이 "정상 동작"하는 모습을 먼저 확인(다운로드 됨, 복사 됨, 팝업 뜸 등).

### (2) 격리 검증 — RBI 격리 브라우저로
RBI의 UG(서버)가 **이 URL에 접근할 수 있어야** 합니다(로컬 file:// 불가). 따라서:
1. 이 사이트를 **UG가 도달 가능한 HTTP(S) URL**에 호스팅(사내 웹서버/테스트 서버 등).
2. 관리 콘솔(admin)에서 해당 URL을 **화이트리스트 + 앱/사이트 정책**에 등록(다운로드/클립보드/인쇄/워터마크 등 정책을 ON/OFF 조합으로).
3. 사용자 포털(예: `https://release.aircode.com/`)에서 그 URL을 격리 실행.
4. 각 섹션을 (1)의 기준선과 **비교** — 정책이 켜진 항목은 차단/무해화/워터마크가 적용되어야 함.

### (3) 정책 매트릭스 검증 팁
- **다운로드 OFF** 정책 사이트로 등록 → E 섹션 다운로드가 차단되는지
- **다운로드 ON + CDR** → .docx/.zip/.exe가 파일보관함 경유·무해화 상태로 표시되는지
- **클립보드 OFF** → D 섹션 복사/붙여넣기 차단
- **읽기전용** → C 섹션 입력 비활성
- **워터마크 ON** → L 섹션(및 전 화면)에 사용자 이메일 타일

## 3. 주의

- E 섹션의 `.exe/.zip/.docx` 파일은 **이름만** 해당 확장자이고 내용은 무해한 텍스트입니다(CDR/백신 정책 트리거 확인용 더미). 실제 악성코드가 아닙니다.
- I(동영상/카메라), J(외부 iframe)는 네트워크·권한이 필요합니다. 격리 환경의 네트워크 정책에 따라 차단될 수 있습니다.
- K(스트리밍)는 UI 모사입니다. 실제 **AI 사이트 DLP**는 ChatGPT/Claude 등 실사이트로 검증하세요.
- 공용 staging(release)에서 다운로드/업로드/카메라 등 부수효과가 있는 케이스는 영향 범위를 확인 후 수행하세요.
